    2. Выберите формат вывода

    Файлы будут объединены в порядке списка. Порядок можно менять кнопками ↑↓.

    У выбранных файлов нет общих форматов вывода — доступно только объединение в PDF.

    3. Настройки конвертации

    Влияет на JPEG, WEBP, DJVU. Выше = лучше качество, больше файл.

    Критично для PDF→изображения, DJVU. Выше = детальнее, больше файл.

    Изменение размера изображения. 0.5 = в 2 раза меньше, 2 = в 2 раза больше.

    Только для конвертации в DJVU.

    Для многостраничных документов (PDF, DJVU, TIFF).

    Уменьшает размер файла в 2-3 раза.

    Удаляет EXIF, XMP и другие метаданные.
